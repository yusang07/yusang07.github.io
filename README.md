# 나의 GitHub Pages 홈페이지

실습 과제 제출용 정적 개인 홈페이지입니다.

## 배포 전 바꿀 내용

1. `index.html`의 `이름을 입력하세요`를 본인 이름으로 수정합니다.
2. 페이지 하단의 `github-id.github.io`를 본인의 GitHub ID로 수정합니다.
3. GitHub에서 저장소 이름을 `본인GitHubID.github.io`로 만들고, 이 파일들을 저장소 최상단에 올립니다.
4. 저장소 **Settings → Pages**에서 **Deploy from a branch / main / (root)**를 설정합니다.

배포 주소는 `https://본인GitHubID.github.io/`입니다.
